About this tool

This generator creates so-called Zalgo text. Use the slider to choose how many marks per character are applied – the default is 30, with a maximum of 200 (macOS limit).

The background is a green, chaotic Zalgo field that is re-randomized every 75 ms. You can disable it anytime via Settings.

Only classic, well-supported combining characters (U+0300–U+036F) are used so the text renders cleanly – no tofu boxes or thick lines.
